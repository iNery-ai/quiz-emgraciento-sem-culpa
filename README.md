# Quiz Emagrecimento sem Culpa

Funil de vendas e quiz interativo de alta conversão para o método **Emagreça sem Culpa**.

## Estrutura do Projeto
- `index.html`: Quiz interativo e personalizado (carregamento rápido, 7 perguntas com micro-compromissos progressivos, cálculo de compatibilidade, prova social e oferta com cronômetro de urgência).
- `quiz.html`: Cópia do quiz interativo.
- `oferta.html`: Página de vendas completa tradicional.
- `logo/`: Ativos de marca, capa do e-book, fotos de alunas, criadora e capas dos order bumps.
- `capi.js`: Integração com Meta Conversions API.
